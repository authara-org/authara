# Examples

Looking for integration examples?

<https://github.com/authara-org/authara-examples>

This repository contains two minimal Go applications showing hosted HTMX and
application-owned React integration styles.

## Available examples

- **Go + HTMX** — hosted Authara login, signup, and account UI with
  `authara-go` middleware
- **Go + React** — application-owned authentication UI using
  `@authara/browser`, `@authara/react`, and an `authara-go`-protected API

Each example includes:

- a working application
- Docker setup
- Authara integration end-to-end

## When to use examples

Use the examples if you:

- want to see a full working setup
- are integrating Authara into an existing app
- prefer learning by reading code instead of docs
